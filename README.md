# MiNT Jobs – Job Listing Platform

A modern job listing platform built with **Next.js 15**, **React 19**, and **TailwindCSS**.  
This project is designed for the Ministry of Innovation and Technology (MiNT) to connect job seekers with opportunities.


Features

- Next.js 15 App Router architecture
- TypeScript support
- Responsive, accessible UI with TailwindCSS
- Job search, filtering, and application flows
- HR team management section
- Modern UI/UX with reusable components

 Tech Stack

- **Framework:** Next.js 15, React 19
- **Styling:** TailwindCSS
- **Language:** TypeScript
- **Animations:** Framer Motion
- **Icons:** Lucide React, React Icons

Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/MiNT-Jobs.git
   cd MiNT-Jobs/job_listing
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open [http://localhost:3000](http://localhost:3000) in your browser.**

Project Structure

```
job_listing/
  app/                # Next.js app directory (pages, routes)
  components/         # Reusable React components
  data/               # Static data (e.g., jobs)
  public/             # Static assets
  styles/             # Global styles (Tailwind)
  ...
```
